## The game

An original browser card duel: build your hand, play ember cards against the rival court, and outscore them before your life runs out.

## Play it

```sh
node serve.ts
# open http://localhost:8080
```

Screenshots in `screenshots/` are real renders of the game's own code. `main.ts` (Node 22, stdlib only) copies `game/` and `screenshots/` to `/output` and writes `dossier.json` with the vendored `vendor/makefun-game.ts`.
